A high-performance, responsive developer portfolio website built with **Next.js 14 (App Router)** and **Tailwind CSS**. Features a modern "Dark & Frosted" glassmorphism UI, server-side rendering, and a working serverless contact form.

🔗 **Live Demo:** [https://your-portfolio-link.vercel.app](https://your-portfolio-link.vercel.app)

---

## ✨ Features

* **Modern UI/UX:** Dark mode aesthetic with "frosted glass" (backdrop-blur) navigation.
* **Responsive Design:** Fully mobile-optimized with a custom hamburger menu.
* **Performance:** Built on Next.js Server Components for lightning-fast page loads (100/100 Lighthouse Score).
* **Dynamic Data:** Skills and Projects are rendered dynamically using map functions for easy updates.
* **Working Contact Form:** Integrated with **Web3Forms** for serverless email delivery (no backend required).
* **SEO Optimized:** Includes dynamic Metadata, Sitemap, and Robots.txt configuration.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** Heroicons (SVG)
* **Form Handling:** [Web3Forms](https://web3forms.com/)
* **Deployment:** [Vercel](https://vercel.com/)
